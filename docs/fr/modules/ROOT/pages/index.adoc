= Dirac
:description: Implémentation MicroProfile Metrics 5.1.1 — compteurs, jauges, histogrammes, minuteries exposés en OpenMetrics / Prometheus et JSON, zéro librairie tierce, zéro contention, Java Modules strict, prête pour jlink.

[.text-center]
image::dirac-logo.png[Dirac,300,role=module-logo]

[.lead]
Dirac est l'implémentation MicroProfile Metrics 5.1.1 de l'écosystème Vidocq. Elle mesure l'état d'exécution d'une application — compteurs, jauges, histogrammes, minuteries — et l'expose en OpenMetrics / Prometheus text et JSON, sans jamais altérer l'observable par l'observation. Les annotations CDI (`@Counted`, `@Timed`, `@Gauge`) sont câblées via xref:vauban::index.adoc[Vauban], l'endpoint optionnel `GET /metrics` est servi par xref:cassini::index.adoc[Cassini], et la configuration `mp.metrics.*` est résolue via xref:ravel::index.adoc[Ravel].

== Origine du nom

**Paul Dirac (1902-1984)**, physicien anglais, lauréat du prix Nobel 1933. Auteur de l'équation de Dirac (équation relativiste de l'électron, 1928), il prédit l'existence de l'antimatière par pure symétrie mathématique, et fonde avec Fermi la statistique d'occupation des fermions. Voir https://fr.wikipedia.org/wiki/Paul_Dirac[la fiche Wikipédia].

Dirac a posé le cadre formel qui sépare l'observable de l'instrument — son formalisme bra-ket ordonne la mesure quantique sans confondre l'état avec le geste qui le sonde. Le runtime Dirac applique la même discipline aux métriques d'application : pas de `synchronized`, pas de `ThreadLocal`, des compteurs `LongAdder` sans contention, et `System.nanoTime()` partout pour la résolution temporelle. L'instrumentation est orthogonale au code métier, jamais intrusive sur le chemin chaud.

== Trois traits identitaires

. **Zéro librairie tierce** — pas de Micrometer, pas de Dropwizard Metrics, pas de SmallRye Metrics. Seule `microprofile-metrics-api` est compilée dans `dirac-core`. Les formatters OpenMetrics et JSON sont écrits à la main avec `StringBuilder`.
. **Zéro contention sur le chemin d'instrumentation** — `LongAdder` pour les compteurs, `AtomicLongArray` pour les histogrammes, `System.nanoTime()` pour les minuteries, `ConcurrentHashMap` pour les registres. Aucun `synchronized`, aucun `ThreadLocal`, aucun verrou plateforme — virtual-thread-friendly par construction.
. **Java Modules strict + jlink validé (M9)** — chaque artefact Dirac a son `module-info.java`. `dirac-mp-metrics-api` est un repackage local de la spec MP Metrics 5.1.1 avec `module-info.class` explicite, livré pour que `jlink` n'ait pas à traverser un module automatique sans nom canonique.

Dirac consomme l'écosystème de bas en haut : xref:chappe::index.adoc[Chappe] sert l'endpoint, xref:cassini::index.adoc[Cassini] expose la ressource JAX-RS `GET /metrics`, xref:vauban::index.adoc[Vauban] orchestre les intercepteurs et la BCE `DiracExtension`, xref:ravel::index.adoc[Ravel] résout les clés `mp.metrics.*`. Dirac ajoute la couche d'observation — compteurs, histogrammes, formatters — sans rien réécrire ailleurs.
